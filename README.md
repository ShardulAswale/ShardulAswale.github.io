# Shardul Aswale — AI Engineer Portfolio

React and Vite portfolio with a coffee-inspired design, Latte/Espresso themes and reduced-motion support.

## Local development

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
```

The static output is written to `dist/`.

## Hosting

GitHub Pages publishes the site at https://shardulaswale.github.io/.
In repository Settings → Pages, choose **GitHub Actions** as the source.
The deployment workflow builds and publishes each push to `main`, and can also be run manually.
No API keys or external backend are required.

## Content

Featured projects link to their actual implementation branches. The cybersecurity chatbot's documented configuration limitation is shown explicitly. Reported ML metrics describe the MSc study evaluation rather than a live production service.
